# Security

## Report a vulnerability

Report a vulnerability through GitHub Security Advisories. On the repository that hosts this code, open Security, then Advisories, then Report a vulnerability.

If the advisory form is unavailable, email security@pdfcraft.invalid. That address is a placeholder. The .invalid domain is reserved and does not deliver mail. Replace the address when the project publishes a security contact.

## Supported versions

`pdfcraft-pdf` and `pdfcraft-forms` are `0.1.0`. `pdfcraft-orgchart` is `0.1.1`. `pdfcraft-post` is `0.2.0`. A fix lands on the default branch. There is no separate support branch.
