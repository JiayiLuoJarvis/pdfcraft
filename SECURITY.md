# Security

## Report a vulnerability

Report a vulnerability through GitHub Security Advisories. On the repository that hosts this code, open Security, then Advisories, then Report a vulnerability.

If the advisory form is unavailable, email security@quire.invalid. That address is a placeholder. The .invalid domain is reserved and does not deliver mail. Replace the address when the project publishes a security contact.

## Supported versions

`quire-pdf`, `quire-forms`, and `quire-orgchart` are version `0.1.0`. That is the first publishable release. A fix lands on the default branch. There is no separate support branch.
